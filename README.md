<p align="center">SSH into persistent dev boxes.</p>

Just:

1. Put your SSH public key in [Authentik settings](https://login.datalab.tuwien.ac.at/if/user/#/settings) in the “dev.box SSH Public Key” field
2. `ssh herdr@dev.box.datalab.tuwien.ac.at`

Why?

1. Secure sandbox that is not your laptop.
2. Connect from different devices to the same session.
3. Manage long running agentic tasks.
